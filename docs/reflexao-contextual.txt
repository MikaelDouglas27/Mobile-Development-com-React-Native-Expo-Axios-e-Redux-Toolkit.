Os aplicativos móveis facilitam o acesso às lojas e a consulta de produtos pelo celular.
No e-commerce, isso permite que o cliente encontre o que procura com mais praticidade.
Para essa experiência funcionar bem, as telas precisam ser claras e fáceis de utilizar.
Neste projeto, os produtos foram separados em categorias masculinas e femininas.
Essa organização ajuda na navegação e permite consultar os detalhes de cada produto.
Um dos desafios ao consumir uma API REST é lidar com a demora ou a falha na resposta.
Por isso, o aplicativo informa quando está carregando e mostra uma mensagem se houver erro.
Também oferece a opção de tentar novamente, sem precisar fechar e abrir o aplicativo.
O Axios realiza as consultas, enquanto o Redux Toolkit guarda os dados do login em memória.
A tela de detalhes recebe o ID do produto e busca suas informações na API DummyJSON.
O projeto aplica os conceitos de componentes, estado e navegação previstos na disciplina.
A separação das telas, dos serviços e dos estilos facilita a leitura e a manutenção do código.
